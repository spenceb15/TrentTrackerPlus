# Before publishing

- [ ] Obtain employer/IP authorization to publicly share the code and screenshots.
- [ ] Confirm the public sample data are invented and do not expose client names, business operations, staff, or private correspondence.
- [ ] Verify no authentication credentials, internal URLs, or company files are included.
- [ ] Open `index.html` and test dashboard, navigation, task edits, and reload persistence.
- [ ] Review public screenshots visually.
- [ ] Enable Pages (Settings → Pages → deploy from main/root).
- [ ] Replace `USERNAME` placeholder in README and Handshake fields with your actual public GitHub Pages URL.
- [ ] Do not claim operational Gmail/Calendar integrations until tested on a permissioned environment.
- [ ] Do not claim time saved, emails handled, or usage metrics without actual pilot measurements.
